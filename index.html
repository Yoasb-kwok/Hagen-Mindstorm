    About this studio
    
      
    Hagen Mindstorm is a classroom robotics studio for courses built around SPIKE Prime word blocks and Python. Programs run on a virtual driving base in the browser, so the course can continue without the SPIKE app.
    
      
    Ports, motor names, and the generated Python follow that course: motor_pair, color_sensor, distance_sensor, force_sensor, and light_matrix. The Sensors block chooses which port the distance sensor, color sensor, and press sensor use. Distance blocks are in centimeters. On a SPIKE hub, distance_sensor.distance() returns millimeters, so the generated code includes distance_cm().
    
      
    The Learn lab is a k-nearest neighbors classifier. Sensor mode stores hub readings. Photo mode stores pictures from the device camera or from uploaded files, with at least 9 photos for each class. A prediction block takes a vote in this browser. When prediction is keeps watching and runs its stack once when that class appears. When the class changes, the other when stack runs.
    
      
    Hub connects a SPIKE Prime hub from Chrome or Edge over Bluetooth. Turn the hub on and leave the SPIKE app closed, then pick the hub in the browser list. The hub reports which port has a motor, distance sensor, color sensor, or press sensor, and those letters fill the movement motors and the sensor port block. Run sends the Python on screen to program slot 0 and starts it. Stop ends that program. The on-screen arena stays a preview. Sensor numbers switch to the hub while it is connected.
    
      
    Arrow keys, the hub button, and the force button stand in for the hardware when no hub is connected. Prediction blocks use the Learn lab in this browser. A hub has no learner module.
    
      
    Undo is ⌘Z or Ctrl+Z. Delete removes the selected block and anything attached under it. Click a block, then click a palette block, to attach it. The gold line shows the spot.
